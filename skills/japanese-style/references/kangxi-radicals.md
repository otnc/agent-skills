# 康熙部首と対応する漢字

康熙部首（U+2F00〜U+2FD5）の全214字。たとえば「⾧」は部首記号の U+2FA7、「長」は漢字の U+9577。画面では似ていても、文字列の検索や照合では区別される。通常の文章では、文脈に合う漢字を使う。

`lint.js` は康熙部首を1字ごとにエラーとして示し、その1字を NFKC で正規化した結果を候補に出す。対応先は Unicode の互換分解によるものなので、日本で使う字体まで決める表ではない。たとえば「⿒」の対応先は「齒」だが、現代の日本語では文脈によって「歯」が自然。

辞書で部首自体を示す箇所や、原文の文字を正確に記録する箇所では、記号をそのまま使う。氏名や固有名詞、引用、識別子を編集するときは元の表記を確かめる。NFKC は全角括弧なども変えるため、修正は混入を確認した箇所に絞る。

この表の範囲は康熙部首。CJK 部首補助や CJK 互換漢字、異体字セレクターは別の文字や仕組みとして扱う。[Unicode の康熙部首一覧](https://www.unicode.org/Public/18.0.0/charts/nameslist/2f00/)、[Unicode 正規化の仕様](https://www.unicode.org/reports/tr15/)
