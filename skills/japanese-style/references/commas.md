# 読点「、」の使い方

回答、進捗報告、手順書、コードコメントでは読み誤りを防ぐ位置にだけ読点を打つ。読み手は読点の位置で読む速さを落とす。係り先が1つに決まる文に打った読点は読む手間を増やすだけになる。文はまず読点を付けずに書き、読み誤る位置にだけ足す。

「日時、担当者、連絡先を記録します。」のように並列する語句の間の読点は項目の区切りを示す記号として使う。会話の相づちとその先の発言の間や創作の地の文では間やリズムのために打ってよい。引用、画面のラベル、コードの表記は原文を保つ。

## 打つ位置

読点を打つのは次の3つの場合である。

- 係り先を取り違えると伝わる内容が変わる位置。「明日公開する記事を確認する。」と「明日、公開する記事を確認する。」では明日する作業が違う。「担当者は急いで、設定を変更した利用者に連絡した。」では読点によって「急いで」が「連絡した」にかかる。
- 同じ種類の文字が続いて語の切れ目が分からない位置。「設定が空の場合既定値を使う。」は「場合既定値」と漢字が続くため「設定が空の場合、既定値を使う。」と書く。ひらがなが続く箇所は漢字やカタカナに書き換えて切れ目が見えるならそちらを先に試す。
- 60字を超える文を前半と後半に分ける位置。先に文を2つに分けられないかを確かめる。分けられないときは61字から120字の文に1つ、121字から180字の文に2つ打つ。

## 打たない位置

次の位置では読点を消しても係り先が1つに決まるか、取り違えても内容が変わらない。

- 主題の後。「この関数は」「このテストでは」「設定には」のように「は」「では」「には」で終わる語句の後には打たない。主題の直後に長い語句が続くときも打たない。
- 文頭の接続語の後。「そのため」「したがって」「しかし」「また」「ただし」「一方」の後には打たない。
- 条件や理由の節の後。「保存先を指定しなかった場合は」「入力が空のとき」「設定が古いので」の後には打たない。節が長くても文が60字以内なら打たない。
- 対比や逆接でつないだ節の境目。「テストは通ったが本番ではリクエストが失敗した。」のように文が60字以内なら「が」の後にも打たない。
- 直後の語にかかる語句の後と短い成分の間。「保存した、ログ」「確認して、ください」のように一続きの表現を区切らない。「AをBに」のような短い成分の間にも打たない。

次の表は読点を外しても読み方が変わらない文の例である。

| 見直す文 | 修正例 |
| --- | --- |
| この設定は、いつでも変更できます。 | この設定はいつでも変更できます。 |
| 先に、トークンを、確認してください。 | 先にトークンを確認してください。 |
| 保存した、ログを確認します。 | 保存したログを確認します。 |
| 更新後は再起動が必要だと、判断しました。 | 更新後は再起動が必要だと判断しました。 |
| 変更内容を確認して、ください。 | 変更内容を確認してください。 |
| ただし、オフラインでは検索できません。 | ただしオフラインでは検索できません。 |
| 保存先を指定しなかった場合は、設定ファイルと同じディレクトリにログを書き込みます。 | 保存先を指定しなかった場合は設定ファイルと同じディレクトリにログを書き込みます。 |
| このテストでは、本物のデータベースの代わりに、呼び出しを記録するだけのオブジェクトを渡します。 | このテストでは本物のデータベースの代わりに呼び出しを記録するだけのオブジェクトを渡します。 |

## 60字を超える文

「設定ファイルの読み込みに失敗したときは標準の値で起動し、起動後に管理画面の警告欄で読み込めなかったファイル名と行番号を確認できるようにする。」は70字ある。まず文を分けて「設定ファイルの読み込みに失敗したときは標準の値で起動する。起動後は管理画面の警告欄で読み込めなかったファイル名と行番号を確認できる。」と書けないかを試す。1文のままにするときは前半と後半の境目の「起動し」の後に読点を1つだけ打つ。

## 語順や見出しを直すところ

- 読点の位置で修飾先が決まる文はかかる語を近くに置けるか試す。「昨日編集した設定をステージング環境で読み込んだ」なら編集した時点が分かる。「編集した設定をステージング環境で昨日読み込んだ」なら読み込んだ時点が分かる。語順で係り先が決まれば読点は要らない。
- 長い条件、短い副詞、目的語が同じ動詞にかかる文では長い条件を先に出し、短い語句を動詞の近くにまとめる。「すぐに、保存後にプレビューが表示されなかった場合は、ページを再読み込みします。」は「保存後にプレビューが表示されなかった場合はすぐにページを再読み込みします。」と書ける。
- 手順の見出しで「設定を、保存する」のような型が続くなら「設定を保存する」のように操作をそのまま示す。「原因は、設定の未保存。」のような見出しは本文から確認できる結果に合わせて「保存前の変更は反映されない」と書ける。話題だけを案内する見出しなら「設定の保存と反映」のような名詞句も使える。

## 読み直しの手順

1. 読点をすべて外した文を読み、係り先を取り違えると内容が変わる位置と語の切れ目が分からない位置を探す。
2. 見つけた位置は語順を入れ替えるか文を分けて直せないかを先に試す。直せないときだけ読点を足す。
3. 60字を超える文は2つに分けられないかを確かめる。分けられないときは前半と後半の境目に打つ。
4. 残した読点は1つずつ消してみて、消すと読み方が変わるかを確かめる。変わらない読点は消す。
