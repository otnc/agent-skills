# agent-skills

[English](README.md) | **日本語**

A generated aggregation of otnc's `skills_*` agent-skill repositories: every skill published there becomes installable from this single source with the [skills CLI](https://github.com/vercel-labs/skills).

> [!NOTE]
> `skills/`, `sync-state.json` and the skill list sections of the base documents are generated by `cmd/sync`. Do not edit them here; changes belong in the source repositories listed below.

## インストール

```bash
# このリポジトリにあるスキルの一覧
npx skills add otnc/agent-skills --list

# 特定のスキルをインストール
npx skills add otnc/agent-skills@fix-unnatural-line-breaks

# 特定のエージェントに入れる
npx skills add otnc/agent-skills@token-saver -a claude-code -a codex
```

## 過去のバージョン

同期したリリースにはそれぞれ `<リポジトリ>@<タグ>` というタグが付く(例: `skills_fix-unnatural-line-breaks@v0.4.0`)ため、過去のバージョンもこのリポジトリからそのままインストールできます。

```bash
npx skills add https://github.com/otnc/agent-skills/tree/skills_fix-unnatural-line-breaks@v0.4.0
```

## このリポジトリの更新のしかた

予約されたワークフローが1日に2回(日本時間の10:30と22:30)実行され、オンデマンドでの実行もできます。公開された `otnc/skills_*` リポジトリは自動的に検出されます。取り込まれるのは、次のすべてを満たすリポジトリです。

- **公開(public)である** — privateリポジトリが取り込まれることはない
- **本当にスキルのリポジトリである** — ルートまたは `skills/` 直下に `SKILL.md` がある
- **リリース済みである** — 公開済み(draftでもprereleaseでもない)GitHubリリースが1つ以上ある

除外したいリポジトリは [`sources.json`](sources.json) に列挙できます。上のスキル一覧と [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) の元リポジトリ一覧は、同期のたびに再生成されます。新しいスキルリポジトリの追加方法は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) を参照してください。

## IssueとPull Request

このリポジトリは生成物です。スキルの中身に関するIssueとPull Requestは[元のリポジトリ](#含まれるスキル)で開いてください。ここにマージされた変更は、次の同期で上書きされます。ここでIssueやPull Requestを開くのは、同期の仕組みそのもの(`cmd/sync`、ワークフロー、生成されるドキュメント)が壊れている・バグがある場合だけにしてください。
